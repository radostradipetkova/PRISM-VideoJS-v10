What to listen for using Windows Narrator

  1. Use Windows + Ctrl + Enter to enable Narrator, then Tab into the player.
  2. In test 1, Narrator should identify the portrait video and its Play/Pause, timeline, volume, speed, captions and EXPLORE controls. EXPLORE should show three named chapters.
  3. In test 2, EXPLORE and the captions button should disappear; Play, Seek, Volume and Fullscreen must remain usable.
  4. In test 3, another creator's real spoken video should play with an English caption track. This clip requires an internet connection.
  5. Press Escape inside the Optical Index and confirm focus returns to EXPLORE. Use Windows + Ctrl + Enter to turn Narrator off.

Important: The automated source check inspects DOM/media states, not actual Narrator speech. Passing it alone does not certify screen-reader announcements.
