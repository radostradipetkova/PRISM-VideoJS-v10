PRISM.
AN INTERFACE FOR TIME.

What if a video player felt less like a toolbar and more like an optical instrument? PRISM is a custom, reusable Video.js v10 skin built for precise navigation without making the controls the main event.

THE CHALLENGE

Make the everyday act of seeking feel intentional, while keeping familiar playback controls immediately available.

THE APPROACH

An Optical Loupe for genuine frame previews, a chapter index for exploration, and an interface that recedes during viewing.

THE OUTCOME

A working, keyboard-accessible Video.js v10 skin that can live inside another website—exactly as it does here.
